2. 토지권 (HGB / HGU / BOT-BGS / Sewa)

인도네시아 토지권 형태와 만료 시점은 골프장 인수에서 가장 중요한 실사 항목. HGB(Hak Guna Bangunan, 건물권) 최장 80년, HGU(Hak Guna Usaha, 사업권) 최장 95년, BOT/BGS(Build-Operate-Transfer) 합의된 기간 후 양도 의무, Sewa(임대)는 단기.

인도네시아 골프장 인수 위험 체크리스트

1. 토지권 (가장 큰 위험)

HGB/HGU 만료 시점과 갱신 비용. 갱신 거부 시 자산 가치 0. BPN 직접 조회 필수.

2. 인허가 (특히 IMB / SLF / AMDAL)

건축 허가(IMB)와 사용 적합 증서(SLF) 미보유 또는 만료 시 영업 정지 가능. AMDAL(환경 영향 평가)는 일정 규모 이상 의무.

3. 회원권 부채 (refundable membership)

30년 환매 의무가 우발 부채로 자리잡고 있음 (P001: IDR 50bn). 환매 청구가 집중되면 현금 압박. 만기 도래 패턴 분석 필수.

4. 세무 분쟁 잔여 청구

이의신청 결과 부분 인용 + 미응답 통지 잔존은 추가 부과 위험. AR에 공시된 분쟁 + 미공시 진행 중 사안 모두 법무·세무 자문으로 점검.

5. BPJS / 노동 컴플라이언스

BPJS Ketenagakerjaan + Kesehatan 의무가입 누락 시 행정처분. 캐디·외주 인력의 BPJS 등록 상태 확인.

6. 환경 / NJOP 토지세 상승

NJOP(과세표준)는 정부 재산정으로 상승하면 PBB(재산세) 부담 증가. P001은 이를 명시적 사업 위험으로 공시.
