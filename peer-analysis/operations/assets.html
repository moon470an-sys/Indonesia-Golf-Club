4. FY2025 시설·자산 후속 (Cycle 110)

13/13 peer FY25 추출 후 시설 데이터 가용성

본 사이트는 원래 FY22-24 시설 정량 (코스/홀/면적). FY25 AR 11 peer 가용 시점에서 시설 데이터 확장 가능성 점검.

FY25 시설 데이터 가용성 (현재 본 사이트 미추출):
• DMIG·PIPG·GOLF·MDLN·KIJA·SMDM 시설 정량 (코스/홀/면적/정규직) → FY24 AR Profil/Wilayah 섹션에서 본 사이트 추출 완료. FY25 AR Profil 섹션에 동일 데이터가 있을 가능성 높으나 본 사이트 미추출 (FY25 추출은 P&L·Segment Note 중심).
• BKDP·SMRA·BSDE·DILD·MKPI·BKSL FY25 시설 데이터: 본 사이트 Cycle 92-103 추출은 모두 Segment Note 또는 P&L 범위. 시설 (코스 수·홀·면적·정규직) 정량은 별도 추출 필요 — 단, 이 6 peer는 모두 Golf 직접 운영 없음 (관계사 운영 또는 미보유) 확인. 본 사이트의 시설 비교는 6 peer (DMIG·PIPG·GOLF·MDLN·KIJA·SMDM) Golf 단독 운영자에 한정.
• 관련 발견: MDLN FY25 Penyusutan +104.1% 비중 1.5배 확대 (cost-hr.html Cycle 86) → 자산 base 증가 신호. 자산 증가의 구체적 내용 (신규 코스/시설/장비) 식별은 AR Note 11 (Aset Tetap) 별도 추출 필요 (본 사이트 미추출).
